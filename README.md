# Weather App ⛅

Welcome to the **Weather App**, a sleek and responsive web application that provides real-time weather information for cities around the world. This app is perfect for checking current weather conditions with a clean and intuitive interface.

## 🎥 Working Demo

Watch the app in action: [YouTube Demo](https://youtu.be/JhYuqjkdhu4)

## ✨ Features

- 🌍 **City-Based Weather Search**: Enter any city to get current weather data.
- 🌡️ **Temperature, Conditions & Icons**: See real-time temperature, weather condition, humidity, and weather icons.
- 📱 **Responsive Design**: Fully responsive interface for both desktop and mobile screens.
- ⚡ **Instant Updates**: Real-time fetch from open weather API to keep your data fresh.

## 🛠️ Technologies Used

- **React.js**: For building the interactive user interface.
- **Material UI**: For sleek, responsive design and components.
- **CSS**: For additional styling and layout customization.
- **Weather API**: To fetch live weather data.

## 💾 Getting Started

To run this project locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/theparinikakath/Weather-App.git
   ```

2. **Install dependencies**

   ```bash
   cd Weather-App
   npm install
   ```

3. **Set your API key**

   * Create a `.env` file in the root directory.
   * Add your OpenWeatherMap API key like this:

     ```
     REACT_APP_API_KEY=your_api_key_here
     ```

4. **Run the application**

   ```bash
   npm start
   ```

   The app should open at `http://localhost:3000`.
